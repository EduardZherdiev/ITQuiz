Поддерживаемые языки: en, ru, uk.
Английская версия обязательна.
Для опубликованного вопроса обязательны переводы ru и uk.
Все переводы должны иметь одинаковый смысл.
Каждый вопрос имеет уникальный положительный числовой ID.
ID нельзя менять или повторно использовать.
Повторный импорт с тем же ID обновляет вопрос.
Если меняется смысл вопроса, создаётся новый ID.
Каждый вопрос относится ровно к одной существующей теме.
Код темы должен точно совпадать с кодом в базе, например ALGO.
difficulty может быть только basic, common или advanced.
Каждый вопрос содержит ровно 4 варианта ответа.
Ровно один вариант имеет correct: true.
Остальные три варианта имеют correct: false.
Все варианты должны быть тематически правдоподобными.
Варианты должны быть примерно одинаковыми по длине и стилю.
Нельзя подсказывать правильный ответ длиной, формулировкой или грамматикой.
Правильный ответ не должен всегда находиться на одной позиции.
Вопрос должен проверять конкретное объективное знание.
Не допускаются вопросы, зависящие от мнения или личного опыта.
Формулировка должна иметь только один однозначный ответ.
Explanation должен объяснять причину правильности ответа.
Если используется код, он должен быть корректным.
Если ответ зависит от версии технологии, версия должна быть указана.
Устаревшая информация допускается только с указанием версии или периода.
Нельзя использовать дублирующиеся или почти одинаковые вопросы.
Вопросы должны быть короткими и удобными для чтения на телефоне.
В JSON не должно быть лишних полей, ошибок, комментариев и trailing commas.
Файл должен быть сохранён в UTF-8.
Для удаления вопроса лучше использовать is_active: false, а не удалять его из базы.
